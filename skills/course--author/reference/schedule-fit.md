# Course schedule fit

Treat available time as a hard budget, not a suggestion.

1. Budget in minutes. Make the drill `estMinutes` values sum to the available budget and state the arithmetic explicitly, for example `45 + 50 + 25 = 120 minutes`.
2. Front-load novel and high-risk material into the peak block. Never schedule new material late in the day.
3. End each day with retrieval and review, not acquisition.
4. Put a full mock at the interview's real clock time, one day before the interview. Do not put it at the end of the last day; leave time to act on what it exposes.
5. Name a sacrifice zone and an explicit drop order. Name what is never dropped: core round-format practice, retrieval, and the full mock when applicable.
6. Hard-stop the evening before. No new material on interview morning.
7. Match practice to the actual round format. For a front-end round, include appropriate practice outside the runner if necessary; retired UI drills are not supported.

For each day, record the peak block, acquisition block, retrieval block, and stop time. If the budget does not fit, drop the sacrifice zone in the declared order rather than silently extending the day.
